# Smart Task Manager

A simple Python command-line task manager with basic priority sorting.

## Current Features
- Add a new task
- View all tasks
- Delete a task
- Automatic priority sorting (tasks containing words like "important", "urgent" get higher priority)

## How to Run
1. Make sure Python 3 is installed.
2. Download `task_manager.py`.
3. Run it with: `python task_manager.py`
